# Условия использования VOLNA

_Последнее обновление: 25.09.2026_

## 1. Что это
VOLNA — бесплатный десктоп-клиент для прослушивания музыки SoundCloud с открытым исходным кодом ([github.com/ResokaU/volna](https://github.com/ResokaU/volna)), распространяемый по лицензии MIT.

## 2. Использование сторонних сервисов
Приложение обращается к публичным API сторонних сервисов — SoundCloud, LRCLIB, Discord — и полагается на их инфраструктуру:
- весь музыкальный контент воспроизводится через официальный SoundCloud Widget и публичное API SoundCloud. VOLNA не скачивает и не пиратит музыку;
- при использовании вы обязуетесь соблюдать [Условия использования SoundCloud](https://soundcloud.com/terms-of-use) и [Политику конфиденциальности SoundCloud](https://soundcloud.com/privacy-policy);
- интеграция с Discord подчиняется [Условиям Discord](https://discord.com/terms).

## 3. Ваш аккаунт
Вход в SoundCloud через VOLNA необязателен и выполняется от вашего имени. Вы отвечаете за сохранность своего oauth-токена и за действия, совершённые через ваш аккаунт. VOLNA не имеет доступа к вашему паролю.

## 4. Отказ от гарантий
Приложение предоставляется «КАК ЕСТЬ», без каких-либо гарантий. Владелец репозитория не несёт ответственности за:
- работоспособность сторонних API (SoundCloud может в любой момент изменить или закрыть их);
- любые убытки, потерю данных или неудобства, связанные с использованием приложения;
- содержание музыки и текстов, найденных через SoundCloud и LRCLIB.

## 5. Ограничения использования
Запрещается использовать VOLNA для:
- скачивания и распространения защищённого авторским правом контента;
- обхода технических ограничений SoundCloud, нарушающих его условия;
- любых действий, нарушающих законодательство вашей страны.

«Антиблок» (DNS-over-HTTPS, ECH, прокси) предназначен для обеспечения доступа к сети в условиях её блокировки/деградации провайдером и не является инструментом пиратства — воспроизведение всегда идёт через официальные механизмы SoundCloud.

## 6. Изменения
Условия могут обновляться; актуальная версия всегда в этом файле. Продолжая использовать новые версии приложения, вы принимаете обновлённые условия.
