# 🌊 VOLNA

Красивый десктоп-плеер SoundCloud на Electron: неон, ambient-свечение, караоке-текст и маскот.

## Запуск

```bash
npm install
npm start
```

Сборка установщика и портативной версии:

```bash
npm run dist
```

Готовые сборки лежат в [Releases](https://github.com/ResokaU/volna/releases).

## Как работает поиск

Старый `api.soundcloud.com` с фиксированным client_id больше не работает (403).
VOLNA ходит через **api-v2.soundcloud.com** — то же публичное API, что использует сам сайт:

- `client_id` динамически извлекается из JS-бандлов soundcloud.com и кэшируется;
- при ротации ключа приложение само обновит его при следующем поиске;
- запросы идут через IPC-прокси в main-процессе (`net.fetch`), т.к. api-v2 не отдаёт CORS-заголовки для чужих origin;
- воспроизведение — через SoundCloud Widget (iframe), client_id не нужен;
- можно вставить **любую ссылку SoundCloud** (трек / плейлист / артист) в поиск — откроется сразу.

## Фичи

### 🎧 Музыка
- Поиск: треки / артисты / плейлисты, сортировка и фильтры по длительности
- Открытие ссылок SoundCloud через resolve (трек, плейлист, профиль)
- Мировые чарты + русские табы трендов
- «Мне повезёт», Radio (похожие треки), Load More
- Командная палитра `Ctrl+K` с живым поиском треков

### ☁️ Аккаунт SoundCloud
- Вход через окно сайта или по oauth-токену
- Поток «Для вас» из подписок
- Лайки с сервера + двойная синхронизация (локально и на SoundCloud)

### 📝 Караоке
- Синхронизированный текст через LRCLIB
- Подсветка строки, клик по строке = seek
- Ручная подгонка ±0.5с и ручной поиск текста, fallback на Genius

### ❤️ Библиотека
- Лайки с сортировкой (по дате / имени) и быстрым фильтром
- Плейлисты: создание, переименование, удаление, удаление треков
- История прослушивания (последние 100)
- Очередь с drag-and-drop и «Играть следующим»
- Обои пользователя с затемнением

### 🎛️ Плеер
- Shuffle / Repeat / Radio mode
- Громкость + Mute, seek по прогресс-бару с тултипом времени
- Sleep Timer с мягким затуханием
- Now playing в трее (название трека в меню и тултипе)
- Настройка «держать экран включённым» при воспроизведении
- Mini Player режим
- Круговой визуализатор и анимированные волны
- Ambient-свечение обложки за плеером
- Маскот (8 вариантов, вкл/выкл в настройках)

### ⌨️ Горячие клавиши
- `Space` — play/pause
- `←` / `→` — prev/next
- `Shift + ←` / `→` — seek ±5s
- `↑` / `↓` — volume
- `F` — фокус на поиск
- `L` — лайк текущего
- `M` — mini player
- `1-8` — переключение view
- `Ctrl+K` — командная палитра- `Ctrl +` / `Ctrl -` / `Ctrl 0` — масштаб интерфейса
- `Esc` — закрыть модалку/меню
- `Ctrl+Q` — выход
- `F1` — список шорткатов

### 🛡 Антиблок
- DNS-over-HTTPS через Cloudflare
- ECH (шифрование SNI)
- Поддержка прокси (socks5/http)
- Диагностика доступности хостов SoundCloud

### ⚙️ Настройки
- 9 акцентных цветов (включая мяту, закат и фиолет)
- Масштаб интерфейса 80–150%
- Громкость по умолчанию, уведомления на лайк
- Запуск свёрнутым в трей, запоминание окна
- Экспорт/импорт лайков и полный backup в JSON

## Структура

```
volna/
├── main.js              # Electron main process
├── renderer/
│   ├── index.html       # HTML
│   ├── styles.css       # CSS
│   ├── app.js           # state + utils + cursor + init
│   ├── search.js        # search view + trending
│   ├── player.js        # player + queue + sleep + radio
│   ├── library.js       # favorites/playlists/history/stats/settings
│   ├── lyrics.js        # караоке-текст (LRCLIB) + маскот
│   └── mascot/          # гифки маскота
└── README.md
```

## Client ID

SoundCloud client_id извлекается автоматически из сайта (см. «Как работает поиск»). Тексты песен — LRCLIB, открытый API без ключа.
